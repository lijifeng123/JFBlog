# Cursor + MCP 自动发布博客测试

这是一篇通过 **Cursor IDE** 中的 MCP 工具自动发布的测试文章，验证完整的发布流程。

## 发布流程

1. 在 Cursor 中编写 Markdown 内容
2. 调用 MCP `publish_blog_post` 工具
3. 自动保存到 `source/_posts/`
4. 自动 Git 提交并推送
5. 自动执行 Hexo 部署到 GitHub Pages

## 技术栈

- **编辑器**: Cursor IDE
- **协议**: Model Context Protocol (MCP)
- **博客框架**: Hexo + NexT 主题
- **部署**: GitHub Pages

## 总结

如果你能看到这篇文章，说明从 Cursor 到博客网站的整个自动化流程已经完全打通！
